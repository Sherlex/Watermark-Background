# Watermark-Background
Генератор минималистичных фонов из SVG иконок

## Особенности
* Отсутствие пересечений иконок и обрезки по краям
* Случайное расположение с изменением масштаба и поворотами при каждой генерации
* 2 варианта иконок: цветные и в виде водяных знаков - режим генерации выбирается на странице.

## Структура проекта
```
watermark_background/
├── watermark_background.html   # Основная страница
├── main.js              # Логика генерации, обработчики кнопок
├── config.js              # Настройки
├── icons/               # Папка с SVG‑иконками
│   ├── primogem.svg
│   ├── stellar-jade.svg
│   ├── polychrome.svg
│   └── oroberyl.svg
```

## Быстрый старт
1. Скачайте файлы проекта.
2. Добавьте файлы иконок в формате SVG в папку icons (имена файлов должны соответствовать значениям в массиве ICON_SRC в config.js.
3. Откройте watermark_background.html двойным кликом — фон сгенерируется.
4. Кнопка Retry генерирует новую случайную композицию в выбраннм режиме.
5. Кнопка выбора режима меняет вид иконок на цветную версию или водяные знаки.

## Настройка

### Изменение списка иконок
В config.js определен массив иконок ICON_SRC. Положите свои файлы в папку icons.
Замените пути в массиве ICON_SRC на свои. 
Если хотите добавить новый тип, добавьте путь в массив и сохраните файл config.js.

### Изменение параметров генерации

  Для изменения параметров генерации необходимо редактировать файл config.js.
|   Параметр  	|                      Описание                      	| Значение по умолчанию 	|
|:-----------:	|:--------------------------------------------------:	|:---------------------:	|
| BG          	| Цвет фона                                          	|               #C4D9A3 	|
| OPACITY     	| Прозрачность иконки                                	|                  0.35 	|
| PER_ICON    	| Количество иконок каждого вида                     	|                    18 	|
| MIN_GAP     	| Минимальное расстояние между иконками разных видов 	|                    25 	|
| SAME_DIST   	| Минимальное расстояние между иконками одного вида  	|                   280 	|
| MARGIN      	| Отступ от края                                     	|                    50 	|
| SCALE_RANGE 	| Диапазон случайного масштаба                       	|           [0.65, 1.1] 	|
| MAX_ROT     	| Максимальный угол поворота (в градусах)            	|                     6 	|
